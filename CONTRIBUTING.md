# Contributing

Dob Defender is an owner-directed alpha project. Please open an issue to discuss a change before proposing code.

## Design constraints

Preserve the approved Dobsonian telescope geometry and artwork, mobile controls, laser position, scoring, lives and restart behaviour unless a change is explicitly approved.

## Pull requests

Include a summary, the complete playable HTML, relevant documentation updates, and what was actually tested. Keep changes narrowly scoped and do not claim Android testing unless it occurred.
